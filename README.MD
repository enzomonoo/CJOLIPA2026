<h1>Diferenças do Livro</h1>
O Livro de C++ 23 para Windows possuí codigos que utilizam funcionalidades que foram introduzidas 
na versão 23 do C++, os codigos escritos neste repositório foram escritos tentando utilizar 
funcionalidades apresentadas no C++ 26. A maior diferença é a utilização dos comandos print ao 
invés dos comandos cout apresentados no livro.
